Table Timer

For any game: free discussion or turn-by-turn speaking

👥 2–20 playersTools
▶ Start with the app

Table Timer is a free tool in Board Game MC that keeps time with voice reminders, for any game with discussion or turn-based speaking.

📖 How to play

  1. Free discussion: one countdown with reminders at one minute, thirty seconds and ten seconds.
  2. Turns: each player gets a fixed time in seat order, and the voice calls the next player.

💡 Tips

  • Turn mode calls players by seat, great for any deduction game with speeches.
  • Add player names and the voice will call people by name.

❓ FAQ

Can I use the timer for other games?

Yes, it works for any game with discussion or turn-based speaking.
