# 🎲 桌遊主持人 · Board Game MC

**語音自動主持＋計時，不用再有人當主持，大家一起玩！**
A free voice narrator and timer for party board games, so nobody has to sit out as the moderator.

👉 **https://bill2712.github.io/boardgame-mc/** · [简体中文](https://bill2712.github.io/boardgame-mc/zh-hans/) · [English](https://bill2712.github.io/boardgame-mc/en/)

純前端 web app，手機瀏覽器打開就能用，可以「加入主畫面」離線使用。
Runs entirely in the browser and works offline once added to your home screen.

## 功能 Features

- 🔊 **語音旁白**：粵語、普通話、English（瀏覽器內建語音）· Cantonese, Mandarin or English narration
- 🌐 **繁體 / 简体 / English 介面**，和語音語言分開設定 · Three interface languages, set separately from the voice
- 🗣️ **玩家名字**：語音直接叫名（「阿明發言」）· Calls players by name
- 🃏 **電子派牌**：翻牌動畫，沒有實體卡也能玩 · Digital dealing with card-flip animation
- ⏱️ **計時器**：圓形倒數、剩一分鐘／三十秒／十秒語音提醒、震動 · Ring timer with voice reminders and vibration
- 🪪 **再看身份**：忘記身份時按住按鈕再看一次 · See your role again, hold-to-view
- 📖 **遊戲中看規則**：玩法和角色攻略，旁白自動暫停 · Rules and role tips mid-game, narration pauses
- 📊 **戰績**：自動記錄每款遊戲勝方 · Win stats per game
- 📝 **自訂詞庫**：誰是臥底、Just One、沙律碗等可加入自己的詞語 · Custom word lists for word games
- 🔍 搜尋、分類、人數篩選、收藏、最近玩過 · Search, filters, favourites, recently played
- 🌙 夜晚星空、白天日出動畫；深色／淺色主題；全螢幕；保持螢幕開啟 · Night sky / sunrise, dark & light themes, full screen, wake lock
- 📱 PWA：可加入主畫面、離線使用 · Installable and works offline

- 攻略文章：新手主持指南、按人數選遊戲、推理遊戲必勝心法（`js/guides.js`）· Guide articles

## 開發 Development

```bash
npm start          # http://localhost:8000
npm test           # 測試所有遊戲流程 / game script tests (Node 18+)
npm run build      # 重新生成 SEO 頁面 / regenerate static pages + sitemap
```

沒有 build step 也沒有 dependency：`index.html`、`games/`、`en/`、`zh-hans/` 都由 `scripts/build.mjs` 生成，修改遊戲資料後記得 `npm run build`（CI 會檢查）。
No runtime dependencies. Pages are generated by `scripts/build.mjs`; run `npm run build` after changing game data (CI checks this).

其他工具 Other tools:
- `scripts/og.cjs`：用 Playwright 生成分享圖片 `og/*.jpg`
- `scripts/gen-t2s.mjs`：用 OpenCC 生成繁→简對照表 `js/t2s-map.js`（`npm i --no-save opencc-js` 後執行）

### 部署 Deploy

Repo **Settings → Pages → Deploy from a branch → `main` / `(root)`**。

## 加新遊戲 Adding a game

每個遊戲是 `js/games/` 裡的一個檔案；內容（分類、顏色、技巧、FAQ）放在 `js/content.js`。
Each game is one file in `js/games/`; display content (category, colours, tips, FAQ) lives in `js/content.js`.

```js
export default {
  id: 'my-game',
  emoji: '🎯',
  name: tx('中文名', 'English name'),
  tagline: tx('…', '…'),
  players: { min: 4, max: 8, default: 6 },
  rules: { zh: ['…'], en: ['…'] },
  roles: [{ id: 'spy', name: tx('間諜', 'Spy'), team: 'evil', max: 2 }],
  options: [{ id: 'talk', type: 'number', label: tx('討論時間', 'Discussion'), min: 1, max: 10, unit: 'min', default: 3 }],
  defaults(n) { return { roles: { spy: 1 } }; },
  deck(setup) { /* full role list */ },
  check(setup) { return { errors: [], warnings: [], summary: tx('…', '…') }; },
  async run(ctx, setup) {
    await ctx.say(tx('天黑請閉眼。', 'Everyone, close your eyes.'));
    await ctx.act(5);                       // action window
    await ctx.timer(setup.opts.talk * 60);  // discussion timer
  },
};
```

`ctx` 還有 `buttons()`、`choose()`、`deal()`、`widget()`、`board()`、`phase()`、`seat()`（會用玩家名字）等，詳見 `js/runner.js`。
Then add it to `GAMES` in `js/games/index.js` and run `npm run build`.
