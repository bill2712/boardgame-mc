想玩一夜终极狼人但没有人想当主持？桌游主持人会用粤语、普通话或英文语音自动主持，包括夜晚流程、计时和电子派牌，所有人都可以一起玩。一夜终极狼人又名一夜终极狼人、一夜狼人、One Night Ultimate Werewolf。

📖 玩法

  1. 卡牌数量 = 玩家人数 + 3：每人一张，中间放三张。
  2. 夜晚各角色按次序醒来行动，卡牌可能被交换，你最后的身份以面前的卡为准。
  3. 天亮后讨论，时间到所有人同时指向一位玩家，最高票（至少 2 票）的玩家死亡。
  4. 死者之中有狼人，村民阵营胜；没有狼人死，狼人阵营胜；皮匠死则皮匠独赢。

🧭 一夜终极狼人角色攻略

🎭

狼人

  • 声称自己是捣蛋鬼或酒鬼，因为他们看不到新卡。
  • 如果中间有狼人，可以声称自己是预言家看过中间。
🎭

预言家

  • 看中间两张卡可以排除很多可能性。
  • 尽快分享信息，帮大家定位狼人。
🎭

强盗

  • 偷到狼人卡你就变成狼人，要转换阵营思考。
  • 如果偷到好人，大方说出交换过程。
🎭

捣蛋鬼

  • 交换两个说法矛盾的人，制造信息。
  • 记住你交换了谁，对推理很重要。
🎭

皮匠

  • 表现得可疑但不要太夸张。
  • 可以假装是狼人，引导大家投你。

💡 玩家技巧

  • 强盗和捣蛋鬼会换卡，所以你最后的身份未必是开始时看到的那张。
  • 如果大家都说自己是村民，中间三张卡可能藏著狼人。
  • 狼人可以声称自己是捣蛋鬼或酒鬼，因为这些角色看不到自己的新卡。
  • 皮匠要扮得可疑但又不太明显，才会被投出去。

❓ 常见问题

一夜终极狼人需要几多张卡？

玩家人数加三张：每人一张，中间放三张。App 会自动检查卡数。

夜晚的角色次序是什么？

化身幽灵 → 狼人 → 爪牙 → 守夜人 → 预言家 → 强盗 → 捣蛋鬼 → 酒鬼 → 失眠者。
